# Medialane Docs

**Everything you need to create, collect and build on Medialane.**

[docs.medialane.io](https://docs.medialane.io) is the knowledge hub of the Medialane platform: the open rails for creators, collectors, businesses and builders, and the foundation for creator capital markets onchain.

## What's inside

| Section | For |
|---|---|
| [Learn](https://docs.medialane.io/learn) | Programmable IP, licensing, the Creator Launchpad, the marketplace, remixing and protecting your work |
| [Apps](https://docs.medialane.io/apps) | medialane.io, the Starknet app, the portal and the DAO |
| [Developers](https://docs.medialane.io/dev) | The SDK, the API, contracts and building with AI agents |
| [Guidelines](https://docs.medialane.io/guidelines) | Community guidelines, terms and privacy |
| [DAO](https://docs.medialane.io/dao) | Governance, the MDLN token and the Creators Fund |
| [Support](https://docs.medialane.io/support) | FAQ and contact |

Found something unclear or out of date? Open an issue or a pull request. Improvements to the docs are always welcome.
